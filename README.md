# my-project4

15種類のサイト（15 Different Website Types）

このプロジェクトでは、15種類の異なるウェブサイトを作成しています。  
This project contains 15 different types of websites, each in its own directory (and corresponding branch).

## サイト一覧 / Site List

| # | Directory | Branch | Site Type | Description |
|---|-----------|--------|-----------|-------------|
| 1 | `01-portfolio/` | `site/portfolio` | 🧑‍💻 Personal Portfolio | Developer portfolio with projects, skills, and contact |
| 2 | `02-blog/` | `site/blog` | 📝 Blog | Technology blog with posts, categories, and sidebar |
| 3 | `03-ecommerce/` | `site/ecommerce` | 🛒 E-Commerce | Online store with products, cart, and navigation |
| 4 | `04-landing-page/` | `site/landing-page` | 🚀 Landing Page | SaaS product landing page with pricing and features |
| 5 | `05-restaurant/` | `site/restaurant` | 🍝 Restaurant | Elegant Italian restaurant with menu and reservations |
| 6 | `06-news/` | `site/news` | 📰 News | Newspaper-style news site with breaking news and articles |
| 7 | `07-photography/` | `site/photography` | 📷 Photography | Masonry photo gallery with services and contact |
| 8 | `08-music/` | `site/music` | 🎸 Music / Band | Rock band site with discography and tour dates |
| 9 | `09-travel/` | `site/travel` | ✈️ Travel | Travel blog and booking site with destinations |
| 10 | `10-fitness/` | `site/fitness` | 💪 Fitness / Gym | Gym website with programs, trainers, and membership |
| 11 | `11-tech-startup/` | `site/tech-startup` | 🤖 Tech Startup | AI SaaS startup with dashboard preview and testimonials |
| 12 | `12-education/` | `site/education` | 📚 Education | Online learning platform with courses and instructors |
| 13 | `13-real-estate/` | `site/real-estate` | 🏠 Real Estate | Property listings site with search and agents |
| 14 | `14-event/` | `site/event` | 🎤 Event / Conference | Tech conference site with speakers and schedule |
| 15 | `15-charity/` | `site/charity` | 🌱 Charity / Nonprofit | NGO site with causes, progress bars, and donations |

## ブランチ構成 / Branch Structure

各サイトは独立したブランチに対応しています。  
Each site corresponds to an independent branch:

- `site/portfolio` — Personal Portfolio
- `site/blog` — Blog
- `site/ecommerce` — E-Commerce Store
- `site/landing-page` — Product Landing Page
- `site/restaurant` — Restaurant Website
- `site/news` — News Website
- `site/photography` — Photography Portfolio
- `site/music` — Music Band Site
- `site/travel` — Travel Blog & Booking
- `site/fitness` — Fitness & Gym
- `site/tech-startup` — Tech Startup (AI SaaS)
- `site/education` — Online Education Platform
- `site/real-estate` — Real Estate Listings
- `site/event` — Event / Conference
- `site/charity` — Charity / Nonprofit
